|---|---|---|
| id | bigint PK | |

| name | varchar | |
| email | varchar UNIQUE | |
| password | varchar | hashed |

| last_login_at | timestamp nullable | |

## products
| column | type | notes |
|---|---|---|
| id | bigint PK | |
| category_id | bigint FK -> categories.id | |
| supplier_id | bigint FK -> suppliers.id nullable | |
| sku | varchar UNIQUE | |
| name | varchar | |
| slug | varchar UNIQUE | |
| description | text nullable | |
| price | numeric(14,2) | |
| cost_price | numeric(14,2) nullable | |
| stock_quantity | integer | source of truth stock |
| minimum_stock | integer default 0 | low stock alert |
| is_available | boolean | POS visibility |
| is_favorite | boolean default false | |
| image_url | text nullable | |
| created_at | timestamp | |
| updated_at | timestamp | |
| deleted_at | timestamp nullable | soft delete |

Relationship:
- belongsTo category
- belongsTo supplier
- hasMany transaction_items
- hasMany stock_movements

Business Rules:
- historical transaction preserved
- soft delete only
- stock authority centralized

# POS MODULE

## transactions
| column | type |
|---|---|
| id | bigint PK |
| transaction_code | varchar UNIQUE |
| cashier_id | bigint FK -> users.id |
| subtotal | numeric(14,2) |
| tax_amount | numeric(14,2) default 0 |
| discount_amount | numeric(14,2) default 0 |
| grand_total | numeric(14,2) |
| payment_status | enum(PENDING, PAID, FAILED, VOID) |
| transaction_status | enum(DRAFT, COMPLETED, CANCELLED) |
| paid_at | timestamp nullable |
| created_at | timestamp |
| updated_at | timestamp |

Relationship:
- belongsTo users (cashier)
- hasMany transaction_items
- hasMany payments

Business Rules:
- immutable after completed
- rollback if payment failed

---

## transaction_items
| column | type |
|---|---|
| id | bigint PK |
| transaction_id | bigint FK -> transactions.id |
| product_id | bigint FK -> products.id |
| product_snapshot_name | varchar |
| product_snapshot_price | numeric(14,2) |
| quantity | integer |
| subtotal | numeric(14,2) |
| created_at | timestamp |

Relationship:
- belongsTo transactions
- belongsTo products

Purpose:
- historical pricing integrity
- preserve old transaction detail even if product changes

---

## payments
| column | type |
|---|---|
| id | bigint PK |
| transaction_id | bigint FK -> transactions.id |
| payment_method | enum(CASH, QRIS, DEBIT, CREDIT_CARD, E_WALLET) |
| paid_amount | numeric(14,2) |
| change_amount | numeric(14,2) default 0 |
| payment_reference | varchar nullable |
| payment_status | enum(PENDING, PAID, FAILED) |
| paid_at | timestamp nullable |
| created_at | timestamp |

Relationship:
- belongsTo transactions

---
